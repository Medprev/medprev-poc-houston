## Causa raiz

O serviço `medprev-web-app-backend-graphql` (repositório `Medprev/medprev-web-app`) tem uma chamada HTTP de saída (`http.client.request`, GET) para o CMS headless `cms.medprev.app` — usada dentro do resolver GraphQL `seoSpecialtyPageQuery` → `seoSpecialtyBySlug`, ao menos no exemplo investigado, para buscar dados de cidade (`/api/cities?...filters[slug]...`). Essa chamada falha de forma intermitente com `ECONNRESET` / "socket hang up" desde `first_seen` (19:07:19 01/02/2026 BRT (epoch 1769983639360 · 2026-02-01T22:07:19.360Z)) e segue ocorrendo até `last_seen` (13:47:48 11/09/2026 BRT (epoch 1789145268066 · 2026-09-11T16:47:48.066Z)).

**Classificação: SINAL, mas de baixo impacto imediato — 644 ocorrências, 100% `handling: handled`, 0% `unhandled`** (medido via `analyze_datadog_error_tracking_errors` agrupado por `error.handling`, filtrado por `issue.id`, na janela `window_from`–`window_to`). Repositório: `Medprev/medprev-web-app`.
